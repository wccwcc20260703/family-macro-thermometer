# 家庭宏观温度计

面向家庭用户的宏观与市场环境看板。它把公开指标转换为可解释的环境温度，并提供七项决策温度计、历史分位线、美元流动性四项核心指标、中国增长与信用解读、A 股资金脉冲、课程重点行业验证、全球市场事件轴和每日大白话总结。

## 自动更新

GitHub Actions 每天北京时间 08:30 自动运行，也支持手动触发。脚本只使用无需密钥的公开数据：

- 国家统计局：国内月度宏观指标。
- 中国人民银行：社会融资、货币与贷款结构。
- 上海证券交易所、深圳证券交易所：逐券融资余额与融资买入额。
- FRED（圣路易斯联储）：有效联邦基金利率、10 年期实际利率、广义美元指数和 NFCI 金融状况指数。
- 美联储、美国劳工统计局与美国联邦选举委员会：议息、通胀、就业与联邦选举日程。
- Nasdaq IPO Calendar：只收录已给出日期且拟募资至少 5 亿美元的大型 IPO；未定档项目不会推测日期。
- 东方财富公开行情：主要市场价格、A 股成交额、课程重点行业 ETF 代理与 ETF 资金公开统计；个别品种使用 Yahoo Finance 或腾讯行情作为备用源。

如果某个来源暂时不可用，脚本会保留上一次成功数据，并在页眉和对应图表的数据日期中明确标注，不会用估算值替代官方数据。

## 使用方式

- 综合温度使用双尾风险模型：低于 45 为过冷风险、55–65 为机会窗口、高于 75 为过热风险；向右升温不再自动等同于机会。
- 全球市场事件轴以今天为中线，左侧显示过去 90 天、右侧显示未来 90 天；同日事件自动合并，点的颜色表示重要性，点击可查看事件背景与市场传导路径。
- 机会与风险地图用横轴表示风险到机会、纵轴表示趋势转弱到改善、圆点大小表示信号强弱；支持回看最近 20 个交易日并点击圆点查看详细依据。
- 温度曲线支持前后翻页与拖动，四项流动性图支持切换 1 年、5 年和全历史区间。
- 每项温度来源都显示谨慎线、观察区、大胆线、当前原始值和历史分位。
- 课程重点行业可以按机会、观察、风险筛选，并展开查看基本面验证条件；ETF 涨跌仅作为市场代理，不等同于课程结论。
