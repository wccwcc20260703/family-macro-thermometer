# 家庭宏观温度计

面向非专业用户的宏观与市场环境看板。它把公开指标转换为 0–100 分的环境温度，提供历史曲线、参照区间、主要支撑与拖累，以及对应的仓位语言。

## 自动更新

GitHub Actions 在每个交易日北京时间 18:30 自动运行，也支持手动触发。脚本只使用无需密钥的公开数据：

- 国家统计局：国内月度宏观指标。
- 东方财富公开行情：美债收益率、美元、原油、黄金、铜与 A 股成交额曲线。

如果某个来源暂时不可用，脚本会保留上一次成功数据并在页面标注，不会用估算值替代官方数据。

## 隐私与版权

仓库只包含公开数据和自行整理的指标规则，不包含付费课程 PDF、音频、逐章原文或附件。
