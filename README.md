# 家庭宏观温度计

面向家庭用户的宏观与市场环境看板。它把公开指标转换为可解释的环境温度，并提供七项决策温度计、历史分位线、美元流动性四项核心指标、中国月度数据专业解读、重要事件时间线和每日大白话总结。

## 自动更新

GitHub Actions 每天北京时间 08:30 自动运行，也支持手动触发。脚本只使用无需密钥的公开数据：

- 国家统计局：国内月度宏观指标。
- FRED（圣路易斯联储）：有效联邦基金利率、10 年期实际利率、广义美元指数和 NFCI 金融状况指数。
- 东方财富公开行情：主要市场价格与 A 股成交额；个别品种使用 Yahoo Finance 或腾讯行情作为备用源。

如果某个来源暂时不可用，脚本会保留上一次成功数据，并在页眉和对应图表的数据日期中明确标注，不会用估算值替代官方数据。

## 使用方式

- 点击综合温度曲线上的事件点可查看事件、指标变化和影响解读。
- 时间线支持前后翻页与拖动，四项流动性图支持切换 1 年、5 年和全历史区间。
- 每项温度来源都显示谨慎线、观察区、大胆线、当前原始值和历史分位。
